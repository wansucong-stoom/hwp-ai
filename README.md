# STOOM AI for 한글

한글 2024에서 Codex와 대화하고 문서 작성·편집을 요청하는 실험적 확장입니다. 우측 작업 창과 본문 우클릭 메뉴에서 사용할 수 있습니다.

**현재 버전: 0.6.28**

## 설치

### 설치 조건

- Windows에 **한글 2024**가 설치되어 있어야 합니다.
- **Codex**가 설치되어 있어야 하며, 사용할 계정으로 로그인해야 합니다. Codex 앱에 포함된 실행 파일 또는 실행 경로에서 찾을 수 있는 Codex 실행 파일을 사용합니다.
- **Node.js 18 이상**이 설치되어 있어야 합니다. 설치 프로그램이 `node.exe`를 실행 경로에서 찾습니다. Node.js 설치 후에도 찾지 못하면 로그아웃 후 다시 로그인하거나 Windows를 재시작해 주세요.
- 한글에서 **도구 → 환경 설정 → 기타 → 개발자 모드**를 켜야 합니다.

### 설치 방법

1. [STOOM AI 0.6.28 설치 파일 다운로드](https://github.com/wansucong-stoom/hwp-ai/raw/refs/heads/main/downloads/STOOM-AI-0.6.28.zip)
2. ZIP 압축을 풀고 `install.cmd`를 실행합니다.
3. 설치가 완료되면 한글을 실행하고 **추가 기능 → STOOM**을 엽니다. 이미 열려 있다면 문서를 저장하고 한글 창을 모두 종료한 뒤 설치하세요.
4. STOOM 창에서 연결 상태와 버전을 확인합니다.

설치 파일은 사용자별 한애드온즈 폴더에 확장을 복사하며, 한글·Codex·Node.js를 설치하거나 로그인하지는 않습니다. 이 확장은 한글 개발자 모드를 직접 켜지 않습니다. 이미 같은 버전이 설치되어 있으면 덮어쓰지 않고 중단합니다. 이전 STOOM 버전의 활성 manifest는 백업됩니다.

## 주요 기능

- 작업 창에서 Codex와 대화하고 모델과 추론 강도를 선택합니다.
- 본문이나 선택 영역의 작성·수정과 표 서식 통일을 요청합니다.
- 문서의 다른 쪽에 있는 내용을 읽고 앞부분의 요약을 갱신합니다.
- 추가 확인이 필요한 경우 질문을 표시하고 답변을 받아 작업을 이어갑니다.

## 현재 한계

실험적 버전입니다. 실제 문서의 페이지 나눔, 병합 셀, 개체와 동시 편집 상황에 따라 작업이 중단되거나 일부만 반영될 수 있습니다. 기존 문서에서는 복사본으로 먼저 확인해 주세요. 이미지의 시각적 내용은 쪽 텍스트 분석에 포함되지 않습니다. 동시 입력은 추가 검증이 필요하며, 여러 작업을 한 번의 실행 취소로 되돌리는 기능은 보장하지 않습니다.

## 개발자용 빌드

저장소에는 확장 소스와 STOOM Codex 연결 모듈이 포함되어 있습니다. 한글 설치본의 인터페이스 DLL과 Node.js를 사용하는 Windows에서 PowerShell로 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\packaging\make-installer.ps1
```

기본 경로 외에 한글이 설치되어 있으면 빌드할 때 `-HancomBin`을 지정할 수 있습니다. 한글과 Codex는 별도로 설치해야 하며 한컴 DLL은 배포 파일에 포함하지 않습니다.
