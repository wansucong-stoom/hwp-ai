# STOOM canonical asset provenance

Updated 2026-10-28 under the user supplied STOOM branding preference.

Canonical source: the approved local STOOM branding source. Both source files were copied verbatim into this project; deployed applications never read that profile folder.

stoom-mark.svg: exact 38 x 29 viewBox, circle (14.5,14.5,r=13.5), stroke #17394c width 2, and path M23 6h14 rotated -35 degrees about (30,6). ChatTheme.StoomMark reproduces this geometry without changing its proportions.

The 16/24/32/64 PNGs were rendered from that geometry with proportional fitting and transparent margins. stoom.ico is the unchanged canonical Windows icon, also embedded as the add-in DLL resource. Manifest, ribbon and workspace marks use these local assets. PWH Desktop already uses byte-identical canonical SVG/ICO files.
